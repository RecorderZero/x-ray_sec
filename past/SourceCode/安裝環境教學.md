title: 無標題

---

以下流程假設是一台**全新安裝好的 Ubuntu 22.04 / 24.04 x86_64 桌機或伺服器**,GPU 已插好但尚未裝任何驅動。整個流程約 30–40 分鐘,中間需要重開機一次。

---

## Step 0. 系統更新與編譯工具

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y build-essential dkms wget curl git \
                    pkg-config libssl-dev ubuntu-drivers-common
```

`build-essential` 和 `dkms` 是後面裝 NVIDIA 驅動、以及編譯 MedPy / scikit-image 的必要條件,不能省。

順便裝 OpenCV 的執行期相依(不裝的話 `import cv2` 會出現 `libGL.so.1: cannot open shared object file`):

```bash
# Ubuntu 24.04
sudo apt install -y libgl1 libglib2.0-0 libsm6 libxext6 libxrender1
# Ubuntu 22.04 請改用
# sudo apt install -y libgl1-mesa-glx libglib2.0-0 libsm6 libxext6 libxrender1
```

---

## Step 1. 安裝 NVIDIA Driver 570

先確認系統認得到卡:

```bash
lspci | grep -i nvidia
ubuntu-drivers devices
```

如果 `ubuntu-drivers devices` 的清單裡沒有 570,先加官方 PPA:

```bash
sudo add-apt-repository ppa:graphics-drivers/ppa -y
sudo apt update
```

安裝:

```bash
sudo apt install -y nvidia-driver-570-open
# 若是較舊的 Turing/Volta 以前的卡,改用 proprietary 版本:
# sudo apt install -y nvidia-driver-570
sudo reboot
```

重開機後驗證:

```bash
nvidia-smi
```

右上角應該顯示 `Driver Version: 570.xx` 與 `CUDA Version: 12.8`。

> **注意 1:** 這裡的 `CUDA Version: 12.8` 是「這張驅動最高支援到的 CUDA runtime 版本」,**不代表你已經裝了 CUDA Toolkit**,也不需要裝。你要的 CUDA 12.8 環境到這一步就已經完成了。
>
> **注意 2:** 若主機開啟了 Secure Boot,安裝過程會要你設定一組 MOK 密碼,重開機時要在藍色畫面選 `Enroll MOK` → `Continue` → 輸入該密碼,否則驅動不會載入、`nvidia-smi` 會失敗。
>
> **注意 3:** 官方 `.run` 檔安裝法請避免,會和 apt 打架。

### (選用)安裝 CUDA Toolkit 12.8

只有在你需要 `nvcc` 自行編譯 CUDA kernel(例如某些自訂 op、或要裝 apex)時才需要。**單純跑 PyTorch 不需要這一步**,因為 pip 版 torch wheel 自帶完整 CUDA runtime。

```bash
wget https://developer.download.nvidia.com/compute/cuda/repos/ubuntu2404/x86_64/cuda-keyring_1.1-1_all.deb
sudo dpkg -i cuda-keyring_1.1-1_all.deb
sudo apt update
sudo apt install -y cuda-toolkit-12-8      # 注意:是 cuda-toolkit-12-8,不是 cuda
```

(Ubuntu 22.04 請把網址中的 `ubuntu2404` 換成 `ubuntu2204`。)

設定環境變數:

```bash
echo 'export PATH=/usr/local/cuda-12.8/bin:$PATH' >> ~/.bashrc
echo 'export LD_LIBRARY_PATH=/usr/local/cuda-12.8/lib64:$LD_LIBRARY_PATH' >> ~/.bashrc
source ~/.bashrc
nvcc -V
```

## Step 2. 安裝 Anaconda

到 https://repo.anaconda.com/archive/ 看最新檔名後下載(以下用一個已知存在的版本示範):

```bash
cd ~
wget https://repo.anaconda.com/archive/Anaconda3-2024.10-1-Linux-x86_64.sh
bash Anaconda3-2024.10-1-Linux-x86_64.sh
```

安裝過程:

1. 按 Enter 讀授權,`q` 跳出,輸入 `yes` 同意
2. 安裝路徑直接 Enter(預設 `~/anaconda3`)
3. 最後問 `conda init` 時輸入 `yes`

**不要用 `sudo` 執行安裝腳本**,否則所有套件都會變成 root 所有,之後 pip 安裝會一路權限錯誤。

```bash
source ~/.bashrc
conda --version
conda config --set auto_activate_base false     # 避免每次開終端機都進 base
```

> Anaconda 的 defaults channel 對員工數 200 人以上的組織有商業授權要求。若是公司環境,建議改裝 Miniconda(`https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh`)並全程使用 conda-forge,後續指令完全相同。

## Step 3. 建立 CFG_DDIM 環境

Python 3.10.19 是 2025/10 發布的 security-only 版本,只有原始碼發布,Anaconda defaults channel 通常沒有,要走 conda-forge:

```bash
conda search -c conda-forge "python=3.10"          # 先確認 3.10.19 在不在清單裡
conda create -n CFG_DDIM -c conda-forge python=3.10.19 -y
conda activate CFG_DDIM
python -V                                          # Python 3.10.19
which python pip                                   # 應指向 ~/anaconda3/envs/CFG_DDIM/bin/
```

若 conda-forge 沒有 3.10.19,用 `python=3.10` 取最新的 3.10.x 即可 — patch 版之間只有安全性修補差異,不影響任何套件相容性。

準備打包工具(舊版 sdist 需要舊的 setuptools 與 Cython 1.x 語法):

```bash
python -m pip install --upgrade pip
pip install "setuptools<70" wheel "Cython<3"
```

## Step 4. 安裝 PyTorch 2.5.1 + cu121

```bash
pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 \
    --index-url https://download.pytorch.org/whl/cu121
```

這會一併帶進 `triton` 與 12 個 `nvidia-*-cu12` runtime 套件,是正常的 — 這也是為什麼 requirements.txt 裡不需要它們。

驗證:

```bash
python -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

預期:`2.5.1+cu121 12.1 True <你的 GPU>`

> cu121 的 wheel 在 CUDA 12.8 driver 上完全可用(CUDA minor version compatibility)。`torch.version.cuda` 顯示 12.1 是 wheel 自帶的 runtime 版本,和 `nvidia-smi` 的 12.8 不衝突。

---

## Step 5. 先處理需要編譯的兩個套件

`MedPy==0.4.0` 與 `scikit-image==0.18.3` 沒有 Python 3.10 的預編譯 wheel,而且它們的 `setup.py` 在建置階段就要 import numpy。在 pip 預設的 build isolation 下會直接失敗,所以要先把 numpy 裝好再關掉隔離:

```bash
pip install numpy==1.23.0
pip install --no-build-isolation MedPy==0.4.0 scikit-image==0.18.3
```

如果 `scikit-image==0.18.3` 仍然編譯失敗(常見於較新的 GCC),退而求其次:

```bash
pip install scikit-image==0.19.3
```

0.19 相對 0.18 的 API 差異主要是 `multichannel` 參數改名為 `channel_axis`,舊程式碼若有用到需要小改。

---

## Step 6. 安裝 requirements.txt

把上一則回覆產生的 `requirements.txt` 放到家目錄,然後:

```bash
conda activate CFG_DDIM
pip install -r ~/requirements.txt
```

Step 5 已裝好的套件版本與檔案內一致,pip 會直接跳過,不會重裝。

---

## Step 7. 驗證整個環境

```bash
python - << 'EOF'
import torch, numpy, scipy, pandas, sklearn, skimage, cv2
import SimpleITK, nibabel, pydicom, medpy, batchgenerators
import torchinfo, torchmetrics, torcheval, visdom, matplotlib

print("python     :", __import__("sys").version.split()[0])
print("torch      :", torch.__version__, "| cuda:", torch.version.cuda, "| available:", torch.cuda.is_available())
print("numpy      :", numpy.__version__)
print("scipy      :", scipy.__version__)
print("skimage    :", skimage.__version__)
print("SimpleITK  :", SimpleITK.__version__)
print("opencv     :", cv2.__version__)

x = torch.randn(4096, 4096, device="cuda")
y = x @ x
torch.cuda.synchronize()
print("GPU matmul :", y.shape, "| mem:", round(torch.cuda.memory_allocated()/1024**3, 2), "GB")
EOF
```

全部印出且 `available: True`,環境就完成了。

---

## Step 8. 備份環境

```bash
conda env export -n CFG_DDIM --no-builds > ~/CFG_DDIM_env.yml
python -m pip freeze | grep -vE "^(torch==|torchvision==|torchaudio==|triton==|nvidia-)" > ~/requirements_backup.txt
```

`grep` 的 pattern 特意寫成 `torch==` 而不是 `torch`,才不會把 `torchinfo`、`torchmetrics`、`torcheval`、`torchfile` 一起濾掉。

## 常見問題

**`nvidia-smi` 找不到指令或顯示 driver mismatch**
驅動沒載入。先 `sudo apt install --reinstall nvidia-driver-570-open` 再重開機;若有 Secure Boot,檢查 `mokutil --sb-state` 並完成 MOK 註冊。

**`conda: command not found`**
安裝時漏了 `conda init`,補執行 `~/anaconda3/bin/conda init bash` 後重開終端機。

**`ImportError: libGL.so.1`**
Step 0 的 `libgl1` 沒裝。

**`AttributeError: module 'numpy' has no attribute 'float'`**
numpy 1.23.0 保留了這些別名但會發 DeprecationWarning,若真的報錯代表 numpy 被升到 1.24+,執行 `pip install numpy==1.23.0` 修回來。

**`Image.ANTIALIAS` AttributeError**
Pillow 被升級了,`pip install Pillow==8.4.0` 修回來。

**pip 在裝 requirements 時把 torch 換掉**
檢查 requirements.txt 裡是否混入 `torch==...`;正常情況檔案內不該有這行。
